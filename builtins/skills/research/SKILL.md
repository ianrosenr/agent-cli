# Research

Research MUST answer a defined question or support a defined decision.

MUST:

- distinguish verified facts, inference, and unknowns
- prefer primary, authoritative, and current sources
- record source version or date when the claim may change
- report material contradictions and uncertainty
- inspect only repository context needed for the question
- return concise findings, evidence, implications, and unresolved gaps
- avoid changing code, architecture, requirements, or repository state unless explicitly authorized

Do not present an inference as a verified fact.
