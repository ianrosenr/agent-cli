# Repository State

`IMPLEMENTED.md` is the concise source of truth for current user-visible capabilities.

Update it only when a capability is added, removed, or materially changed. It MUST NOT become a file-level changelog.

Future work belongs in the issue tracker.

If `IMPLEMENT_ME.md` exists, it MUST be a derived index of issue identifier, title, and optional status/category. Requirements MUST NOT exist only there.

Documentation MUST be updated when a change makes existing documentation materially false.
